# Productr

Productr is a full-stack product management application where users can manage products with image uploads and OTP-based authentication.

## Features

* OTP Authentication
* Add, Update and Delete Products
* Publish / Unpublish Products
* Multiple Image Upload
* Product Image Preview
* Responsive Design
* Protected Routes
* REST APIs

## Tech Stack

### Frontend

* React.js
* React Router DOM
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JWT Authentication
* Express File Upload
* CORS
* Dotenv
